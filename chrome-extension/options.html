One pattern per line. Use https://domain.com/*. Kiji will mask PII on these sites before your prompts leave the browser. Adding a domain outside the defaults will prompt for site-access permission.

Mapping expiration

Default: 300 seconds from creation. Set to 0 to disable expiration. Applies to all clients and existing mappings. Active requests keep their mappings until the response finishes.

Changes are saved in the server's database. An explicit mapping_expiration setting in the server config replaces this value on every restart; otherwise your saved value is kept.

PII profile Detection settings applied to your prompts

Profiles (which entity types to mask, sensitivity and custom patterns) are managed in the Kiji app under Settings → PII Detection. “Server default” follows whichever profile is the default there.
